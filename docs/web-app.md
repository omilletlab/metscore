# Web application

MetSCORE provides a web interface for calculating and exploring MetSCORE without requiring a local Python installation.

The web application uses the same validated Python implementation distributed in the MetSCORE package. It provides a graphical interface around the existing prediction and input-processing functionality rather than a separate implementation of the model.

## Input options

The web application currently supports two input workflows:

- tabular data in CSV or Excel format;
- paired Bruker metabolite and lipoprotein XML reports.

### Example inputs

Each input workflow includes bundled example data that can be used directly from the web application without downloading or preparing any files.

For tabular input, users can:

- run the bundled example dataset directly;
- download the example as CSV;
- download the equivalent example as Excel.

For Bruker input, users can:

- run a bundled pair of metabolite and lipoprotein XML reports directly;
- download either XML report to inspect the expected file structure.

The bundled examples use the same canonical example files distributed with the MetSCORE repository.

## Tabular data

CSV and Excel files may contain one or multiple samples, with one sample per row.

The file must contain the 22 variables required by the MetSCORE model. Required variables are identified by column name, so their order in the input file does not matter.

Additional columns are allowed and are preserved in the downloaded results.

A dedicated sample identifier column is not required.

The same input validation used by the Python package is applied by the web application.

### Single sample

When a file contains a single sample, the application displays the individual MetSCORE result directly.

### Multiple samples

When a file contains multiple samples, the application displays a results table.

Selecting any cell in a row opens the individual result for that sample.

## Bruker XML

The Bruker workflow accepts two XML reports corresponding to one sample:

- one metabolite report generated by B.I.Quant / Quant-PS;
- one lipoprotein report generated by B.I.LISA / PL-5009.

The reports may be uploaded in either order.

MetSCORE identifies the report type from the XML content, checks that both reports correspond to the same sample, validates the required units, extracts the model variables, and calculates the prediction using the standard MetSCORE pipeline.

For additional information about supported report structures and analytical requirements, see the Bruker XML input section in the project README.

## Results

The individual result view emphasizes the MetSCORE value, which ranges from 0 to 1.

Higher values indicate a metabolic profile more strongly associated with the metabolic syndrome phenotype represented by the original model.

The visualization also displays the reference threshold of 0.5 used in the original model.

MetSCORE should be interpreted as a continuous molecular score and not as a standalone clinical diagnosis.

The underlying model outputs `t_pred` and `t_orth_1` are available under **Technical details**.

Input data can also be inspected from the individual result view.

## Downloading results

Results can be downloaded as:

- CSV;
- Excel (`.xlsx`).

Downloaded files preserve the input data and include the MetSCORE model outputs.

## Data handling

Uploaded data are used to calculate MetSCORE through the web application.

The application is designed so that scientific input data are not used for analytics or usage tracking.

Specific deployment, retention, and privacy information will be documented for the public hosted version of the application.

## Research use

MetSCORE is intended for research use.

The web application does not change the analytical requirements or interpretation of the underlying MetSCORE model. Input data should follow the variable definitions, analytical origin, and units described in the MetSCORE documentation.
